# بيانات سوبر الفائق

هذا المجلد مخصص لملفات كتالوج منتجات سوبر الفائق التي يقرأها التطبيق.

ضع ملفات JSON المعتمدة هنا (مثل `catalog_01.json` إلى `catalog_08.json`) وفق مخطط الاستيراد الموجود في التطبيق. وجود هذا الملف التعريفي يضمن تتبع المجلد في Git، لكنه لا يحتوي على المنتجات نفسها ولا يعني أن الكتالوج تم استيراده.
